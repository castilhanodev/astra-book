# Materiais Google Play — versão 2

Arquivos finais:

- `imagem-destaque-1024x500-v2.png` — imagem de destaque 1024 × 500;
- `01-estante-personalizada.png` — estante, importação e frases salvas;
- `02-dicionario-no-texto.png` — consulta contextual durante a leitura;
- `03-progresso-e-conquistas.png` — metas, sequência e conquistas.

As capturas são baseadas na interface real do AstraBook 4.9. Para evitar usar
conteúdo de terceiros na ficha da loja, as capas e os títulos comerciais do
print da estante foram substituídos por exemplos fictícios, e o texto do livro
atrás do dicionário foi desfocado. Nenhuma função nova foi inventada nos
materiais.

`fundo-cosmico-gerado.png` é o fundo original criado especificamente para estas
peças. `estante-real-sem-capas-protegidas.png` e
`dicionario-real-com-fundo-protegido.png` são as bases sanitizadas preservadas
para futuras atualizações da ficha.
