# AstraBook

Leitor de livros em PDF, EPUB e TXT.

## Continuidade do desenvolvimento

O desenvolvimento atual está na branch
`teste/dicionario-mascote-fluidez`. Para continuar em outro computador ou em uma nova tarefa
do Codex, abra [RETOMAR-EM-OUTRO-COMPUTADOR.md](RETOMAR-EM-OUTRO-COMPUTADOR.md).

A correção de seleção em PDF veio da branch `teste/selecao-pdf`. A etapa atual
melhora a apresentação do dicionário, reduz sinônimos frágeis, acrescenta
reações leves do mascote e prepara otimizações da virada de página. Os achados e
as opções de API estão em
[AUDITORIA-DICIONARIO-MASCOTE-FLUIDEZ.md](AUDITORIA-DICIONARIO-MASCOTE-FLUIDEZ.md).

O aplicativo continua em testes. Não publicar na Play Store nem atualizar o
site/produção até o usuário pedir explicitamente.
